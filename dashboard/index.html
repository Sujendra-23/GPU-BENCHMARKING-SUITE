Live verification (WASM)

kernels/reference/matmul_ref.c — the same naive triple-loop reference the CUDA and OpenCL host programs check themselves against — compiled with Emscripten to matmul_ref.wasm and loaded on this page. Pick a matrix size, generate random inputs with a seeded PRNG, and it runs matmul_cpu_reference() right here in your browser, then cross-checks the WASM output against an independent plain-JS implementation of the identical algorithm.

Sizes above 768 are blocked here - the naive O(n³) reference gets slow to run twice (WASM + JS cross-check) on the main thread of a browser tab.

What this does and doesn't prove

  • The WASM correctness check confirms the compiled reference implements the documented naive algorithm correctly on your machine, right now - it does not depend on trusting a server.
  • It says nothing about the CUDA or OpenCL kernel's correctness on this run - that was checked separately, offline, on the hardware listed in the recorded table above, at the time it ran.
  • Live WASM timing and the recorded native CPU timing are not a controlled comparison: different machine, different day, and WASM/JS engine overhead vs a native binary. Use it as a sanity check on order-of-magnitude, not a precise benchmark.
  • No CUDA numbers exist in this repo yet because this project has never been built or run on a machine with an NVIDIA GPU.
